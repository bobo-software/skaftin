## 🤝 Contributing

When adding new features:
1. Create a feature summary document (e.g., `FEATURE_NAME_SUMMARY.md`)
2. Add a quick start guide if applicable (e.g., `FEATURE_NAME_QUICK_START.md`)
3. Update this README with links to new docs
4. Update related documentation (API docs, client SDK, etc.)

## 📝 Documentation Format

All documentation should:
- Start with a brief overview
- Include code examples
- Provide troubleshooting tips
- Link to related documentation
- Be updated when features change
